# CodeAlpha Basic Chatbot

## 📌 Project Overview

A simple Python-based chatbot developed as part of the CodeAlpha Python Programming Internship.

## 🎯 Objective

The objective of this project is to create a basic chatbot that can interact with users through the console and provide responses to common inputs.

## 🛠️ Technologies Used

* Python
* Python standard libraries

## ✨ Features

* Interactive conversation
* User input handling
* Predefined responses
* Exit command
* Console-based interface

## ▶️ How to Run

1. Install Python 3.x
2. Clone this repository
3. Open the project folder
4. Run:

```bash
python chatbot.py
```
